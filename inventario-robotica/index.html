    Como funciona

    Os dados ficam numa planilha do Google e todos veem as mesmas peças. O que você cadastra, edita ou conta é enviado sozinho em alguns segundos, e o site busca novidades dos colegas a cada 15 segundos.

    O indicador ● no topo mostra o estado. Se estiver sem conexão, suas alterações ficam guardadas neste aparelho e são enviadas quando a internet voltar.

    Se duas pessoas mexerem na mesma peça, vale a alteração mais recente. Por isso, dividam a contagem por local.

    Para ter o arquivo Excel: abra a planilha no Google e use Arquivo ▸ Fazer download ▸ Microsoft Excel. O Baixar data.json e o CSV também servem de backup.

    O catálogo oficial é o arquivo data.json publicado no GitHub Pages. Todos veem a mesma lista ao abrir o link.

    O que você altera fica salvo só neste aparelho (o GitHub Pages não é um banco de dados). O topo da tela avisa quando existem alterações ainda não publicadas.

    Para compartilhar alterações: use Mais ▸ Baixar data.json e envie o arquivo ao responsável pelo inventário, que o substitui no repositório. Para juntar várias pessoas, o responsável usa Importar com o arquivo de cada uma — peça por peça, vale a alteração mais recente.

    Dica: para evitar conflito, dividam a contagem por local (cada pessoa um armário).

    Exclusões não são mescladas na importação; exclua direto no aparelho do responsável.
